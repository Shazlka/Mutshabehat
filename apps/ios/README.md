# Qiraat — iOS app for the Mushaf 1441 reader (متشابهات)

Native SwiftUI + UIKit app for iPhone and iPad. Phase 1 is an **offline** Mushaf 1441 reader:
all 604 pages drawn with the exact QCF V2 page fonts, iBooks-style page curl (right-to-left),
two-page spreads on iPad landscape, resume where you left off, surah/juz index.

## First run (MacBook Air, Xcode 27, iOS 27 simulators)

```bash
brew install xcodegen          # once
cd apps/ios
make test                      # builds data + fonts + project, runs every test on an iPhone simulator
make run                       # build and launch on the iPhone simulator
make open                      # open the generated project in Xcode
```

`make fonts` downloads the 604 page fonts (~94 MB, about 4 minutes) once; later runs skip them.

## Layout

| Path | What | In git? |
|---|---|---|
| `project.yml` | XcodeGen spec — the source of truth for the Xcode project | yes |
| `Mutshabehat.xcodeproj` | generated by `make project` | **no** |
| `Sources/` | the app (SwiftUI shell, UIKit page curl, CoreText page view) | yes |
| `UITests/` | XCUITest end-to-end checks | yes |
| `MushafCore/` | Swift package: data, fonts, page layout, navigation — no UIKit, unit-tested with `swift test` | yes |
| `Generated/mushaf.sqlite` | built from `packages/quran-data/mushaf1441/fixtures` by `scripts/ios/build_mushaf_db.py` | **no** |
| `Generated/Fonts/p1…p604.woff2` | QCF V2 fonts, fetched by `scripts/ios/fetch_qcf_fonts.sh` | **no** (licence) |
| `Config.xcconfig` | local Supabase keys (Phase 2) | **no** |

## Rules that carry over from the web reader

- Page geometry is a port of `Mushaf1441Viewer.tsx`; change both or neither (`MushafCore/Sources/MushafCore/PageLayout.swift`).
- Surah header / basmala slots are computed exactly like `pageDecorations.ts` (0 differences across 604 pages).
- A page's glyphs only render in that page's own font. Never fall back to another page's font.
- Draw and measure every token through `QCFFontStore.line(...)`: 198 tokens contain a space the QCF fonts do not have.
