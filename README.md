# Qiraat Android (`qiraat_apk` branch)

Android (Kotlin/Jetpack Compose) port of the Qiraat iOS app, handed over for continued work.

Start with [`qiraat_APK/HANDOFF.md`](qiraat_APK/HANDOFF.md).

- `qiraat_APK/android/` — the Gradle project
- `qiraat_APK/ios_reference/` — read-only copy of the iOS app for comparison
- `qiraat_APK/briefs/` — the prompts used for each implementation phase

Other branches: `main` = web app, `ios/main` = iOS app.
